# 모의면접 강평 (교사용)

고3 모의면접을 준비하고 진행하고 강평을 남기는 **교사용 웹 화면**입니다.

주소: https://chem-kim.github.io/interview-feedback/

## 할 수 있는 것

- **학생 목록**: 반별로 거르고 이름으로 찾기. 학생마다 지원 수, 예상 질문 수, 강평 횟수, 다음 면접 D-day가 보입니다.
- **예상 질문 관리**: 학생이 만든 질문과 교사 질문을 함께 봅니다. 교사 질문은 여러 줄을 붙여넣으면 한 줄에 하나씩 들어가고, 학생에게 보일지 숨길지 정할 수 있습니다.
- **면접ON 보고서 올리기**: 면접ON PDF를 올리면 브라우저에서 질문을 뽑아 둡니다. 교사는 그중 골라 교사 질문으로 넣고, 학생은 10개까지 골라 자기 질문으로 가져갑니다.
- **모의면접 진행**: 면접 유형(서류 10분 / 제시문 15분)과 면접 교사를 고르고 시작합니다. 물어본 질문을 체크하며 진행합니다.
- **강평 기록과 요약정리**: 말로 한 강평을 받아쓰고, [요약정리]를 누르면 AI(Gemini)가 **잘한 점 · 고칠 점 · 다음 연습**으로 정리합니다. 교사가 확인·수정한 뒤 저장합니다.
  - 받아쓴 원문은 시트에만 남고, 학생 화면과 인쇄물에는 정리본만 나갑니다.
  - AI에는 강평 본문만 보냅니다. 이름·반·번호·대학명은 보내지 않습니다.
- **인쇄**: 지원 대학별로 물어본 질문과 강평 정리본을 인쇄합니다.

## 구조

- 이 저장소에는 화면(`index.html`) 하나만 있습니다.
- 데이터는 모두 Google 스프레드시트에 있고, Google Apps Script 웹앱을 거쳐 읽고 씁니다.
- 처음 열면 교사 비밀번호를 묻습니다. 비밀번호가 맞아야 Apps Script가 데이터를 내주므로 이 페이지가 공개돼 있어도 학생 정보는 보이지 않습니다.
- 노트북 크롬 기준으로 만들었습니다. 받아쓰기에 마이크 권한이 필요합니다.
